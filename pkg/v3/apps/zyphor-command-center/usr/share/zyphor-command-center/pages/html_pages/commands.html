Zyphor CLI

Installation: zyphor pkg install zyphor-cli

Note: Zyphor CLI is pre-installed and available by default after operating system installation.

Zyphor CLI Abstraction Layer — A unified command framework that transforms complex Linux operations into simple, consistent, and easy-to-remember commands for developers, administrators, and everyday users.

All Commands

Showing all commands
Category Command Description
SYSTEM sudo zyphor system upgrade Upgrade all installed system packages to their latest available versions from configured repositories, ensuring security updates, bug fixes, and feature improvements are applied.
SYSTEM sudo zyphor system clean Remove package caches, unused dependencies, residual configs, old logs, and temporary files to free disk space and keep the system optimized.
SYSTEM sudo zyphor system clean --dry-run Preview which unused packages and residual configs would be removed. Nothing is changed.
SYSTEM sudo zyphor system clean --deep Run the standard cleanup, then also empty the user's Trash and remove unused Flatpak runtimes.
SYSTEM sudo zyphor system info Display detailed information about the operating system, kernel version, hardware resources, and system environment.
SETUP sudo zyphor setup dev <target> Automatically configure a complete development environment for the selected programming language or technology stack.
SETUP zyphor setup dev version php List the PHP versions that are installed and available, and show which one is currently active.
SETUP sudo zyphor setup dev version php 8.3 Install the chosen PHP version (e.g. 8.3) with the common extensions and switch the active php command to it. Offers to add the Sury PHP repository if the version is not available in your current sources.
SETUP zyphor setup dev version node Show the installed Node.js version and the latest release of each recent Node.js major version, with LTS releases marked.
SETUP sudo zyphor setup dev version node 22 Install the chosen Node.js version (e.g. 22) and switch to it. A minor version such as 22.5 is also accepted and pinned when it is still available.
SETUP sudo zyphor setup dev android-studio Install and configure Android Studio and Flutter for development, including the Android SDK, required build packages, and PATH entries in your shell configuration.
SETUP sudo zyphor setup dev undo php Remove PHP and its extensions, with optional removal of Composer and the Sury PHP repository. Asks for confirmation before anything is removed.
SETUP sudo zyphor setup dev undo node Remove Node.js, with optional removal of the NodeSource repository files.
SETUP sudo zyphor setup dev undo composer Remove Composer from /usr/local/bin.
SETUP sudo zyphor setup dev undo git Remove the Git settings configured by the setup, with an optional, separate prompt for each generated SSH key. Git and OpenSSH themselves stay installed.
SETUP sudo zyphor setup dev undo android-studio Remove Android Studio, Flutter, and the PATH entries added to your shell configuration, with optional removal of the Android SDK and related build packages.
SETUP sudo zyphor setup dev undo os Remove the OS/Distro development tools installed by setup dev os. Packages the base system depends on, such as gzip, python3, and grub-pc-bin, are kept.
SETUP sudo zyphor setup pentest recon Install reconnaissance and scanning tools such as Nmap, Masscan, Amass, and Gobuster for network and target discovery.
SETUP sudo zyphor setup pentest web Install web application testing tools including Sqlmap, Nikto, Burp Suite, ZAP, and Wpscan for auditing web apps.
SETUP sudo zyphor setup pentest wireless Install wireless auditing tools such as Aircrack-ng, Kismet, and Wifite for testing Wi-Fi networks you own or are authorized to assess.
SETUP sudo zyphor setup pentest passwords Install password auditing tools including John the Ripper, Hashcat, Hydra, and Medusa for credential strength testing.
SETUP sudo zyphor setup pentest sniffing Install traffic analysis tools such as Wireshark, Tcpdump, and Bettercap, and configure non-root packet capture.
SETUP sudo zyphor setup pentest forensics Install forensics and analysis tools including Autopsy, Sleuth Kit, Binwalk, and Volatility3 for investigating systems and files.
SETUP sudo zyphor setup pentest exploitation Install exploitation framework tools such as Metasploit, Exploit-DB, and SET for authorized penetration testing engagements.
SETUP sudo zyphor setup pentest full Install the complete pentest toolkit, covering recon, web, wireless, passwords, sniffing, forensics, and exploitation in one run.
SETUP sudo zyphor setup wine Install and configure Wine with 32-bit compatibility, then initialize the default Wine environment for running Windows applications.
SETUP sudo zyphor setup theme light Apply the Windows-10 inspired desktop theme for a bright and familiar user experience.
SETUP sudo zyphor setup theme dark Apply the Kali-Dark inspired desktop theme optimized for developers and low-light environments.
SETUP sudo zyphor setup web-server Sets up an Apache web server by enabling required modules, configuring SSL, creating a VirtualHost, setting the site document root, and enabling and restarting the Apache service.
PACKAGE sudo zyphor pkg install <pkg> Install software packages from configured repositories while automatically resolving required dependencies.
PACKAGE sudo zyphor pkg remove <pkg> Uninstall a package and optionally remove associated dependencies that are no longer required.
PACKAGE sudo zyphor pkg search <key> Search available repositories for packages matching a keyword, name, or partial package identifier.
PACKAGE sudo zyphor pkg list Display all currently installed packages along with their versions and installation status.
SERVICE sudo zyphor service restart <name> Restart a running service to apply configuration changes or recover from operational issues.
SERVICE sudo zyphor service list Lists system services and displays their current running status and whether each service is enabled or disabled at boot.
SERVICE sudo zyphor service start <service> Starts a specified system service using systemd and reports whether the service started successfully.
SERVICE sudo zyphor service status <service> Displays the current status and detailed information of a specified system service.
SERVICE sudo zyphor service stop <service> Stops a specified system service using systemd and reports whether the service stopped successfully.
NETWORK / STORAGE sudo zyphor smb list Lists the available SMB network shares on a specified IP address using the provided username.
NETWORK / STORAGE sudo zyphor smb disk-list Displays a list of available disks and their partition information on the system.
NETWORK / STORAGE sudo zyphor smb disk-mount Mounts an NTFS disk partition to a named directory under /mnt for access through the filesystem.
NETWORK / STORAGE sudo zyphor smb mount Connect and mount a remote SMB/CIFS network share, making it accessible like a local directory.
NETWORK / STORAGE sudo zyphor smb share-add Share a local folder over SMB so it's accessible from other devices, including Windows PCs, on the network.
NETWORK / STORAGE sudo zyphor smb share-list List all folders currently being shared over SMB from this machine.
NETWORK / STORAGE sudo zyphor smb share-remove Stop sharing a folder that was previously shared over SMB.
FTP sudo zyphor ftp upload Transfer files securely from the local system to a configured FTP server.
FTP sudo zyphor ftp download Downloads a file from an FTP server by prompting for the FTP host, username, remote file, and optional local save path.
FTP sudo zyphor ftp list Lists the files and directories available on an FTP server by prompting for the FTP host and username.
SSH sudo zyphor ssh connect Establish a secure encrypted shell session to a remote server for administration and maintenance.
SSH sudo zyphor ssh cmd Execute commands on a remote server over SSH without opening an interactive terminal session.
DOCTOR sudo zyphor doctor scan Analyze the system for configuration issues, missing dependencies, broken packages, and common problems.
DOCTOR sudo zyphor doctor fix Attempt to automatically repair issues detected during a diagnostic scan.
DOCTOR sudo zyphor doctor report Generate a comprehensive diagnostic report for troubleshooting and technical support purposes.
BUILD sudo zyphor build package [dir] Build a Debian package from a project directory, simplifying software packaging and distribution.
BUILD sudo zyphor build repo Generate repository metadata files such as Packages.gz for hosting a Debian-compatible package repository.
CORE sudo zyphor refresh Refreshes the Zyphor OS system by resetting first-boot defaults and rebooting the system to apply them.
CORE sudo zyphor help Display the complete Zyphor CLI command reference, categories, usage examples, and available options.
